<h1>Gasto na Foto</h1>

<p>Gasto na Foto é uma aplicação desenvolvida para facilitar o controle de gastos do dia a dia.</p>

<p>Através de uma foto ou anexo de um comprovante de compra, a aplicação utiliza Inteligência Artificial para interpretar as informações da imagem, identificar os valores e registrar os gastos automaticamente. Dessa forma, o usuário consegue acompanhar e somar suas despesas de maneira rápida e prática.</p>

<h3>HTML5 - Utilizado para estruturar toda a interface e os elementos da aplicação.</h3>

<h3>CSS3 - Responsável pela estilização, organização visual e adaptação da aplicação para diferentes tamanhos de tela.</h3>

<h2>✨ Funcionalidades</h2>

<h4>📷 Fotografia de comprovantes</h4>
<p>Permite fotografar o comprovante diretamente pelo dispositivo.</p>

<h4>📎 Anexo de imagens</h4>
<p>Possibilita anexar uma imagem de um comprovante já existente.</p>

<h4>🤖 Leitura dos comprovantes através de IA</h4>
<p>A Inteligência Artificial analisa a imagem e identifica as informações da compra.</p>

<h4>💰 Identificação dos valores gastos</h4>
<p>Os valores presentes no comprovante são identificados automaticamente.</p>

<h4>🧾 Organização das informações</h4>
<p>Os dados das compras são organizados para facilitar o acompanhamento dos gastos.</p>

<h4>➕ Soma automática dos gastos</h4>
<p>A aplicação calcula automaticamente o total das despesas registradas.</p>

<h4>📊 Acompanhamento do total gasto</h4>
<p>O usuário consegue visualizar o valor total gasto através da aplicação.</p>

<h2>🔄 Como funciona</h2>

<h4>📸 1. Fotografe ou anexe o comprovante</h4>
<p>O usuário envia uma foto do comprovante de compra.</p>

<h4>🤖 2. Inteligência Artificial</h4>
<p>A imagem é enviada para a IA, que analisa as informações presentes no comprovante.</p>

<h4>🧾 3. Leitura dos dados</h4>
<p>A aplicação identifica os dados relevantes da compra.</p>

<h4>💰 4. Identificação dos valores</h4>
<p>Os valores das compras são identificados e organizados.</p>

<h4>➕ 5. Soma dos gastos</h4>
<p>Os valores são somados automaticamente.</p>

<h4>📊 6. Acompanhamento</h4>
<p>O usuário pode acompanhar o total de suas despesas dentro da aplicação.</p>
